# Infographic → Editable PPT

**Canonical skill (keep this in sync):**

[`Junweiw/context-infrastructure`](https://github.com/Junweiw/context-infrastructure) →  
`rules/skills/workflow_infographic_to_editable_ppt.md`

Also indexed from: `rules/skills/INDEX.md`

If you are working in the content-infra workspace, read that file directly.  
If you are in another project, pull the same method from content-infra (or follow the summary below).

## One-line method

Deconstruct the infographic into text / shapes / images / glyphs → approve glyphs → reassemble as layered PPT. Never deliver one flat image as the editable slide.

## Complementary skill

For **non-editable**, full-bleed AI-rendered decks, see content-infra
